# Quantum Computing Laboratory at PESC/UFRJ

Welcome to the GitHub organization of the **Quantum Computing Laboratory** at
**PESC/COPPE, Federal University of Rio de Janeiro (UFRJ)**.

This organization hosts materials related to the lab activities, including:

- student projects and coursework repositories;
- tutorials and study resources;
- code examples and other quantum computing experiments.
